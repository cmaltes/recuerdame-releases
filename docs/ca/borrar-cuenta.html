Esborrar el teu compte

Recuérdame, de Fernando Munguía Hoyo · Darrera actualització: 6 d'octubre de 2026

Pots esborrar el teu compte de Recuérdame i totes les teves dades quan vulguis, de dues maneres.

Des de l'app

  1. Obre Recuérdame i entra amb el teu compte.
  2. Obre el menú lateral i toca Configuració d'usuari.
  3. Toca Esborra el compte i confirma-ho.

S'esborra en aquell moment i es tanca la sessió.

Sense l'app, per correu

Si ja no tens l'app instal·lada, escriu a recuerdame@lamaltesa.dev des del correu amb què entres a Recuérdame, amb l'assumpte «Esborrar el meu compte». El teu compte i les teves dades s'esborraran en un termini màxim de 30 dies i rebràs una resposta quan estigui fet.

Què s'esborra

  • El teu compte: nom, correu electrònic i identificador d'usuari.
  • Els teus recordatoris, amb les seves fotos, adreces i historial. Els que comparties amb altres persones també desapareixen per a elles.
  • Les teves categories i els teus llocs (nom, xarxa Wi-Fi, ubicació i radi).
  • Les teves amistats, sol·licituds i enllaços d'invitació, i els identificadors dels teus dispositius per a les notificacions.

Què es conserva

  • Als recordatoris que altres persones compartien amb tu, l'historial continua dient quan es va fer, però en lloc del teu nom posa «Usuari eliminat».
  • Els suggeriments que vas enviar, publicats a GitHub sense el teu nom ni el teu correu. Es retiren si ho demanes.

No es desen còpies de les teves dades després d'esborrar-les.
